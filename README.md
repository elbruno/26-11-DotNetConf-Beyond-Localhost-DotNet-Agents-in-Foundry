# Beyond Localhost: .NET Agents in Foundry

Audience-safe source bundle accompanying the session. Follow [the demo README](demos/README.md) for five stages: simple MAF agent, host-ready/not deployed, same agent intended for Foundry deployment, local MAF agent calling Foundry Microsoft-Decision-1, and that decision agent intended for Foundry hosting. No Ollama dependency is used.

The only setup script is `demos\Set-DemoEnvironment.ps1`. It configures existing chat and Decision-1 deployments, not build/export/authentication/deployment. Use standard `dotnet build <project> -c Release` separately when needed. Stages 03 and 05 include deployment-ready source, not verified deployed resources. No models are downloaded or created.

In the same PowerShell 7 terminal used for the demos, run `& .\demos\Set-DemoEnvironment.ps1` from this bundle root. Four ordinary visible prompts configure the chat project endpoint/deployment and native Decision-1 resource endpoint/deployment. Existing values/defaults are shown in brackets; blank retains them. Without existing values, only the chat model defaults to `gpt-6-luna`; the other three settings are required. The selected values are printed after all inputs pass validation. These are non-secret endpoint/deployment names, not keys. No credential variables, login or persistent storage are involved. Demos 01/04 use AzureCliCredential; 02/03 use DefaultAzureCredential. Exact upstream Demo 05 uses AzureCliCredential locally and ManagedIdentityCredential when hosted. Settings stay in this process and future children. See the demo README for separate-terminal and identity guidance.

The main example follows [From dotnet run to Foundry Hosted Agent in 3 lines of C#](https://devblogs.microsoft.com/dotnet/from-dotnet-run-to-foundry-hosted-agent-in-3-lines-of-csharp/). Stage 05 preserves its upstream dependency pins, license and notices. Stage 04 links its exact routing logic/contracts, so keep the complete bundle together. Local execution and synthetic tests are not cloud deployment or real inference evidence.

No presentation is included. This source bundle contains no speaker notes, private planning content, credentials, caches, models, audio or build outputs.
