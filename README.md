# Beyond Localhost: .NET Agents in Foundry

This repository accompanies the .NET Conf 2026 session on building .NET agents beyond a local process. The demos progress from local Microsoft Agent Framework agents to hosted Foundry agents, including tool use and structured decision workflows.

See [the demo guide](demos/README.md) for the example sequence, prerequisites, and run instructions.

For session context, see the [.NET Conf 2026 agenda](https://dotnet.microsoft.com/en-us/conf/2026/agenda).
